# Fremdkomponenten

Das Repository enthält nur den eigenen Code der Pflanzendatenbank (MIT-Lizenz, siehe `LICENSE`). Grav, Quark 2 und die Grav-Plugins werden nicht mitgeliefert, sie kommen aus der Grav-Installation. Im Theme `user/themes/pdb-theme` liegen folgende Fremdkomponenten:

| Komponente | Pfad | Lizenz |
|---|---|---|
| Font Awesome Free 7.0.1 (Icons und Schrift) | `css/fontawesome/`, `css/webfonts/` | Icons CC BY 4.0, Schriften SIL OFL 1.1, Code MIT (Lizenzhinweis im Kopf von `all.min.css`) |
| Liberation Sans (Schrift) | `fonts/` | SIL Open Font License 1.1 |
| htmx 2.0.4 | `js/vendor/htmx.2.0.4.min.js` | BSD Zero-Clause |

Die Seite lädt keine Schriften, Icons oder Skripte von fremden Servern; alles wird vom eigenen Server ausgeliefert.
